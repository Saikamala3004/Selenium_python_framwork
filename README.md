# Selenium Python Automation Framework

## Project Overview

This is a Selenium-based test automation framework built using Python and Pytest.

It follows Page Object Model (POM) design pattern and includes:

* Automated login test
* Google search test
* Pytest fixtures
* HTML reporting

---

## Tech Stack

* Python
* Selenium WebDriver
* Pytest
* WebDriver Manager

---

## Project Structure

* `tests/` → Test cases
* `pages/` → Page Object classes
* `conftest.py` → Fixtures
* `reports/` → Test reports

---

## How to Run Tests

```bash
pip install -r requirements.txt
python -m pytest --html=report.html
```

---

## Features

* Page Object Model (POM)
* Parameterized tests
* HTML reporting
* Cross-browser ready (extendable)
